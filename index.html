Sobre mí

Construyo soluciones backend enfocadas en lógica, seguridad y mantenibilidad.

Soy desarrollador backend enfocado principalmente en Java y Spring Boot. Mi formación ha sido autodidacta, complementada con proyectos personales donde he aplicado conceptos de programación orientada a objetos, arquitectura por capas, APIs REST, persistencia de datos y seguridad.

Actualmente continúo fortaleciendo mis conocimientos mediante proyectos como NexoRF y ForgeOps, trabajando con problemas similares a los que pueden encontrarse en aplicaciones empresariales.

Mi objetivo es incorporarme a un equipo de desarrollo donde pueda seguir creciendo como backend developer, aportar mis conocimientos y aprender de profesionales con experiencia.

PROYECTO DESTACADO

NexoRF

Sistema de inventario y picking con simulación RF

Sistema inspirado en procesos reales de operación logística, desarrollado para representar de forma simplificada el control de inventario y las operaciones de picking.

El proyecto cuenta con un backend desarrollado en Java y Spring Boot y una aplicación cliente en JavaFX, incorporando autenticación, autorización mediante roles, persistencia de datos y lógica de negocio.
